# 🔐 Tela de Cadastro

Projeto desenvolvido para praticar HTML, CSS e JavaScript.

## 📌 Descrição

Uma interface moderna de cadastro com foco em design e experiência do utilizador.

## 🚀 Funcionalidades

- Campo para nome
- Campo para email
- Campo para senha
- Botão de cadastrar
- Interface responsiva

## 🛠 Tecnologias utilizadas até agora

- HTML5
- CSS3
